현재 삼각형의 각도 측정값

내각 ∠A 60.0°
내각 ∠B 60.0°
이웃한 내각 ∠C 60.0°
★ 외각 120.0°
1
발견 1

외각과 이웃한 내각의 관계

한 꼭짓점에서 외각과 이웃한 내각을 더하면 직선(평각)이 됩니다!

120.0° + 60.0°
= 180.0°
2
발견 2

외각과 이웃하지 않는 두 내각

외각의 크기는 이웃하지 않는 두 내각의 합과 항상 같습니다!

120.0° =
60.0° + 60.0° (= 120.0°)

종이 각도 찢어 붙이기 체험

두 내각을 떼어서 외각에 딱 맞춰볼까요?

초등학교나 수업 시간에 종이 삼각형의 각을 찢어서 한곳에 모았던 기억이 나나요? 아래 버튼을 눌러 이웃하지 않는 두 내각 ∠A와 ∠B를 외각 위치로 이동시켜 보세요!

신기하죠! 두 내각을 붙이니 외각의 크기와 정확히 빈틈없이 합쳐집니다!

왜 외각은 두 내각의 합과 같을까?

수학적 원리 한눈에 파악하기

1 삼각형의 세 내각의 합은 180° 입니다.
∠A + ∠B + ∠C = 180°
2 외각과 이웃한 내각의 합도 평각(180°) 입니다.
외각 + ∠C = 180°
3 두 식에서 공통인 이웃한 내각(∠C)을 제외하면!

둘 다 180°로 같으므로, ∠C를 양쪽에서 똑같이 빼주면 나머지 부분이 서로 같습니다.

★ 외각 = ∠A + ∠B
